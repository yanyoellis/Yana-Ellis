# Lucent Dentistry

Premium multi-page dental clinic website concept for the Yana Ellis portfolio.

## Run

This project is integrated into the static portfolio site and can be opened directly:

```text
projects/lucent-dentistry/index.html
```

For local browser testing, serve the portfolio root with any static server and open:

```text
http://127.0.0.1:<port>/projects/lucent-dentistry/index.html
```

## Pages

- Home
- Services
- Digital Smile Design service detail
- Doctors
- Dr Elena Park profile
- About
- Pricing
- Reviews
- Contact
- Appointment
- Privacy Policy
- Terms of Use
- 404

## Interactive Features

- Sticky glass navigation
- Mobile menu
- EN / PL / UA interface switcher
- Service search and filters
- FAQ accordion
- Before/after slider
- Reviews filtering
- Frontend form validation
- Multi-step appointment flow
- Quick appointment modal
- Toast notifications
- Back-to-top button
