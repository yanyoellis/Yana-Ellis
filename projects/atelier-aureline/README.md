# Atelier Aureline

Premium multi-page tattoo atelier website concept for the Yana Ellis portfolio.

## Pages

- Home
- Works / Gallery
- Artists
- Maeva Rousseau artist profile
- About
- Process
- Booking
- FAQ
- Contact
- 404

## Features

- English-only interface
- Sticky responsive navigation
- Desktop custom cursor
- Loader with atelier monogram
- Scroll reveal and subtle parallax
- Horizontal featured works row
- Work filtering
- Work modal previews
- FAQ accordion
- Frontend booking and contact form validation
- Generated hero and portfolio cover asset
- Generated artist portraits and tattoo work photography
